Willkommen. Dieses Projekt ist ein
**<span data-variable="productType">{{variable.productType}}</span>**-Projekt, und das bedeutet vor
allem eines:

> **Ihre Dokumentation liegt in einem Git-Repository, und das Repository ist die Quelle der
> Wahrheit.**

Alles Weitere folgt aus diesem Satz. Die Seiten, die Sie schreiben, sind Markdown-Dateien. Ihre
Reihenfolge steht in einer Datei, die Sie lesen können. Eine Änderung wird für Leser sichtbar, sobald
sie den Branch erreicht, der veröffentlicht.

## Falls Sie Document360 schon kennen

Vielleicht haben Sie **<span data-variable="siblingType">{{variable.siblingType}}</span>** verwendet,
den editorzentrierten Projekttyp, bei dem die Inhalte in Document360 liegen und das Portal Ihr
Arbeitsplatz ist. Beide Projekttypen existieren, beide werden unterstützt, und sie sind keine
Entwicklungsstufen voneinander.

> [!IMPORTANT]
> **Der Editor ist derselbe; die Quelle der Wahrheit nicht**
>
> Sie schreiben in beiden Projekttypen in
> <span data-variable="editorName">{{variable.editorName}}</span>. Was sich ändert, ist, wo das
> Ergebnis gespeichert wird und wie es zu den Lesern gelangt.

## Was Sie brauchen

- [ ] Zugang zu diesem Projekt in Document360.
- [ ] Zugang zum dahinterliegenden Git-Repository, falls Sie außerhalb des Portals arbeiten wollen.
- [ ] Sonst nichts. Alles in diesem Abschnitt können Sie allein im Portal erledigen.

> [!TIP]
> **Sie müssen Git nicht verwenden, um hier zu arbeiten**
>
> Autorinnen und Autoren, die das Portal bevorzugen, müssen nie eine Befehlszeile anfassen. Das
> Repository ist die Art, wie die Inhalte *gespeichert* werden, kein Werkzeug, zu dem Sie verpflichtet
> wären. Wer es will, bekommt Git vollständig.
